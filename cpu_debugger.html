CPU-16 / debugger
16-bit custom architecture
idle
MOVH/MOVL split a 16-bit constant across two instructions.
Use label names directly: MOVH R0 loop → high byte, MOVL R0 loop → low byte.
memory
MOVRsrc Rdstcopy register to register (R0–R7)
MOVRsrc Rdst N typecopy with shift — type: LSL LSR ASR, N = 0–15
MOVHRdst valload immediate into high byte (bits 15–8)
MOVLRdst valload immediate into low byte (bits 7–0)
STORERdata RaddrRAM[Raddr] = Rdata
LOADRaddr RdstRdst = RAM[Raddr]
ALU — all update FLAGS
ADDRa Rb RdstRdst = Ra + Rb
SUBRa Rb RdstRdst = Ra − Rb
ADCRa Rb RdstRdst = Ra + Rb + CF  (32-bit add high word)
SBBRa Rb RdstRdst = Ra − Rb − CF  (32-bit sub high word)
CMPRa Rbupdate FLAGS only, no result written
ANDRa Rb Rdstbitwise AND
NANDRa Rb Rdstbitwise NAND
ORRa Rb Rdstbitwise OR
NORRa Rb Rdstbitwise NOR
XORRa Rb Rdstbitwise XOR
XNORRa Rb Rdstbitwise XNOR
MULRa RbBANK2.R0 = Ra×Rb low 16 bits, BANK2.R1 = high 16 bits
DIVRa RbBANK2.R0 = Ra÷Rb quotient, BANK2.R1 = remainder
GETFRdstRdst = FLAGS register
SETFRsrcFLAGS = Rsrc
NOPdo nothing
branches
BEQRa Rb Rjmpjump if Ra == Rb  (unsigned)
BNERa Rb Rjmpjump if Ra ≠ Rb
BLTRa Rb Rjmpjump if Ra < Rb  (unsigned)
BLERa Rb Rjmpjump if Ra ≤ Rb  (unsigned)
BGTRa Rb Rjmpjump if Ra > Rb  (unsigned)
BGERa Rb Rjmpjump if Ra ≥ Rb  (unsigned)
BEQSRa Rb Rjmpjump if Ra == Rb  (signed)
BLTSRa Rb Rjmpjump if Ra < Rb  (signed)
BLESRa Rb Rjmpjump if Ra ≤ Rb  (signed)
BGTSRa Rb Rjmpjump if Ra > Rb  (signed)
BGESRa Rb Rjmpjump if Ra ≥ Rb  (signed)
CALRaddrcall function — saves COUNTER+FLAGS+BANK1 to buffer
RETreturn — restores COUNTER+FLAGS+BANK1 from buffer
system
SWPBBANK0/1/2switch active register bank
SYSRSC|PC Rdstread system register into Rdst
SYSWRsrc SC|PCwrite Rsrc into system register (SYSW R0 PC = jump)
MOVBB0.R0 B1.R3copy register between banks (no bank switch)
MOVBBANK0 R0 BANK1 R3same — alternate syntax
SEIenable interrupts (IF=1)
CLIdisable interrupts (IF=0)
INTNsoftware interrupt vector N (0–63)
IRETreturn from interrupt
TASRaddr Rdstatomic: Rdst = RAM[Raddr], RAM[Raddr] = 1 — ZF=1 if lock acquired
HALTstop execution
flags
CFbit 0carry — set on unsigned overflow (ADD) or borrow (SUB)
ZFbit 1zero — set when result = 0
SFbit 2sign — copy of result bit 15
OFbit 3overflow — signed overflow
IFbit 4interrupt enable
BF0bit 5bank select bit 0 (LSB)
BF1bit 6bank select bit 1 (MSB)
register banks
BANK0R0–R7arguments / return value (caller-saved)
BANK1R0–R7saved registers (auto saved/restored by CAL/RET)
BANK2R0–R7global storage + MUL/DIV results in R0/R1
BANK3R0–R7interrupt handler only (auto on INT/IRET)
PCsystemprogram counter — read/write via SYSR/SYSW PC
SCsystemstack counter — read/write via SYSR/SYSW SC
directives
.org0xADDRset current address
.wordvalueemit raw 16-bit word
label:define label at current address
;comment to end of line
calling convention
R0BANK0argument 1 / return value
R1–R7BANK0arguments 2–8
R0–R7BANK1callee-saved (auto by CAL/RET)
